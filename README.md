Magos vs Dragones 🧙‍♂️🐉
“Magos vs Dragones” es un videojuego desarrollado en Unity y programado en C# como proyecto de desarrollo dentro del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).
El juego combina mecánicas de estrategia y gestión de recursos en un sistema inspirado en los videojuegos tipo tower defense. El jugador debe defender su castillo frente a distintas oleadas de dragones utilizando magos y artefactos colocados estratégicamente sobre el tablero.
---
🎮 Características principales
Sistema de combate por oleadas.
Diferentes tipos de magos con habilidades únicas.
Dragones con distintos comportamientos y ataques especiales.
Sistema de recursos mediante cristales.
Modo infinito con dificultad progresiva.
Sistema de pausa y configuración.
Guardado de progreso entre niveles.
Interfaz visual y efectos sonoros integrados.

⚙️ Sistemas implementados
Sistema de enemigos
Los dragones avanzan por el tablero siguiendo rutas predefinidas. Existen diferentes tipos de enemigos con habilidades específicas.
Sistema de unidades
El jugador puede colocar magos y artefactos utilizando recursos obtenidos durante la partida.
Sistema de recursos
Los cristales permiten comprar nuevas unidades y reforzar la defensa.
Sistema de guardado
El progreso entre niveles se almacena mediante PlayerPrefs.
